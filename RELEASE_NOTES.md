## What's new
- Game mode shows what is really applied while you play (profile, refresh rate, Do Not Disturb, apps closed, floating monitor) with time played, FPS and temperature, and warns when something is missing (root, usage access, overlay permission, notifications).
- The game mode notification shows time, FPS and temperature, and can end the session or show/hide the floating monitor.
- Richer session summaries: 1 % low, stability, CPU and battery max temperature, time the system slowed down because of heat, battery per hour, profile used and how the session ended. Tap the summary notification to open its details; long-press a session to delete it.
- One warning per session when the phone gets very hot, and a clear message if Diablo Mode could not be used or was turned off to protect the phone.
- Options changed while playing (close background apps, Do Not Disturb, floating monitor) now apply right away, and briefly locking the screen no longer ends the session.
- More accurate CPU temperature on more phones: sensors that only look like temperatures (battery charge, power limits) are no longer mixed in, and a single faulty sensor is ignored.
- New diagnostics report (Settings and Games): records which features fail on your phone. It stays on the phone until you share it or attach it to a GitHub issue.
