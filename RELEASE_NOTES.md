## Novedades
- La GPU ahora muestra el nombre real del chip gráfico en cualquier teléfono (por ejemplo, Mali-G57 MC2 o Adreno 610).
- Las notas de cada actualización ahora se muestran como lista de cambios.

## Correcciones
- MediaTek (Redmi Note 13, Redmi Note 14 y otros): ahora aparecen el modelo y la frecuencia máxima de la GPU.
- Si el chip no tiene sensor de temperatura propio para la GPU, se muestra la del SoC y se indica con "(SoC)".
