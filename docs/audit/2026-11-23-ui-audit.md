# UI/UX audit 2026-11-23 — Windows 11 and macOS styles

Branch `ui-audit/2026-11-23` (based on `audit/2026-11-22`). Scope: every page of the app in both interface
styles (Windows 11 and macOS), light and dark themes, the three text sizes, on a phone (compact layout,
width < 600 dp). Not in scope: the floating monitor, the widget and the website.

The visual identity of each style is kept: no colours, fonts, icons or layouts were redesigned. Changes
that would alter how the app looks are listed as proposals at the end and were **not** applied.

## Method
- Code review of every page and the shared components (`Ui.kt`, `Common.kt`, `UiStyles.kt`, `MacShell.kt`,
  `MainActivity.kt`, `SettingsPage.kt`, `Tuning.kt`, `CpuPower.kt` and each `*Page.kt`), checking contrast,
  touch target sizes, TalkBack semantics, text overflow, layout at large text and work on the main thread.
- Screenshots of every page on a real phone (1080×2400, 450 dpi) before and after the fixes, with the build
  produced by GitHub Actions:
  - Windows 11 light, normal text: Processes, Performance (CPU, memory, disk, Wi-Fi, mobile data, GPU,
    battery), App history, Startup apps, Users, Details, Services, Games, Settings.
  - Windows 11 dark, extra-large text: Processes, Performance, Games, Settings.
  - macOS light: Processes and Performance.
- Contrast ratios computed from the palette values (WCAG 2.1: 4.5:1 for normal text).

The screenshots are not committed: they show the tester's installed apps and notifications.

## Proposals (need approval: they change the look)
- **P1** — Short confirmation snackbar after actions ("Task ended", "Restored"), styled for each interface.
- **P2** — A one-line note under controls disabled by Shizuku mode ("Needs root").
- **P3** — Empty state for tables ("No results for …").
- **P4** — Apply "pure black" also to the macOS dark palette.
- **A1** — Unify label typography (several 11/12/13 sp sizes for the same role).
- **A2** — Unify corner radii (4, 6 and 8 dp are mixed in the Windows style).
- **A3** — Move the remaining hard-coded colours (Diablo red, chart colours) into the palettes; the Diablo red
  on the dark card is close to the contrast limit.
- **A4** — One consistent loading text/indicator instead of "Cargando…" in some cards and nothing in others.
