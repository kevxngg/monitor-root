Everything from the Task Manager, on your phone

The same sections you know from Windows 11, adapted to Android. Root access lets you see and control every system process, not just your apps.

Processes

Apps, background and Android processes with their CPU, memory and disk usage. End tasks or turn on efficiency mode.

Performance

60-second graphs for CPU (overall or per core), memory, disk, Wi‑Fi, mobile data, GPU and temperature.

App history

Usage time, CPU time, and Wi‑Fi and mobile data for each app over the last 24 hours, 7 or 30 days.

Startup apps

See which apps start on their own when the phone turns on, and disable them.

Users

Usage per user and work profile, with options to switch to or stop a user.

Details

Full list by PID: change priority or core affinity, suspend processes or end the whole process tree.

Services

Native Android and app services, with options to start, stop and restart them.

Automatic updates

The app tells you when there's a new version and installs it with one tap, without going through the browser.

Floating monitor

A panel on top of any app with CPU, GPU, RAM and temperature gauges, graphs, network, storage and FPS. Four designs (full, compact, gamer and retro), resizable from the corner, and it minimizes to a bubble with the logo that sticks to the screen edge.

Two interface styles

Choose the Windows 11 Task Manager or the macOS Activity Monitor look, in light, dark or pure black for AMOLED screens.

With root or Shizuku

With root you get every feature. Without root, through Shizuku, Monitor reads the whole system and can close apps; anything that changes the system is marked "Root only".

Battery and power mode

24-hour battery history with estimated time remaining, and power modes like Windows 11.

Game mode

When your games open it applies the power mode and the floating monitor, and saves a summary of each session with FPS, temperature and battery.

Alerts

Warnings for high temperature, apps using a lot of CPU in the background and a charge limit.

Installation

It works with root (Magisk, KernelSU, APatch or temporary) or, without root, with Shizuku. It takes four steps.

  1. Download the APKFrom the button above or the Releases section of the repository.
  2. Allow installing unknown appsAndroid asks for this the first time, for your browser or file manager.
  3. Open Monitor and choose how to connect it"Connect with root" (accept your root manager's prompt) or "Connect with Shizuku" (start Shizuku first and accept its permission). You can change it later in Settings.
  4. DoneFuture versions arrive with an in-app prompt.

Requirements

  • Android 8.0 or later.
  • Root (Magisk, KernelSU, APatch or temporary) for every feature, or Shizuku to use it without root.
  • Works with Qualcomm Snapdragon, MediaTek and Exynos processors.
  • Takes up about 2 MB.

FAQ

Does it work without root?

Yes, with Shizuku. Monitor reads processes, CPU, memory, network, storage, battery, temperatures and FPS, and can close apps. Anything that changes the system (power mode, CPU and GPU settings, process priority) and a few readings Android blocks (GPU usage and disk activity) still need root, and the app marks them "Root only".

What's the difference between root and Shizuku?

Shizuku gives ADB-level permissions: it can read almost the whole system, but can't write to the files that control the CPU and GPU. With root, Monitor can do everything. With neither, Android doesn't let apps see other apps' processes.

Does it work with temporary root?

Yes. The app works the same while temporary root is active. Because that kind of root is lost when the phone restarts, you need to enable it again after every restart so the app can read system data and install updates on its own.

Is it free?

Yes. It's free, has no ads, and the code is published on GitHub.

Can it damage my phone?

Viewing information is safe. Ending system processes or services can restart the phone, so the app asks for confirmation first.

Why doesn't the GPU temperature show up?

Some processors don't have their own GPU temperature sensor. In that case the app shows the processor temperature and marks it "(SoC)".

How do I report a problem?

Open a report in GitHub Issues. In the app, under Settings, About, you can copy your device information to include it.
