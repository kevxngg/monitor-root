# Clave de plataforma de prueba de AOSP

Estos archivos son la clave **pública de prueba** de AOSP (`build/make/target/product/security/platform.*`), la misma que trae el código de Android. No son secretos: cualquiera puede descargarlos.

Se usan para firmar `MonitorRoot-system-testkey.apk`, que solo funciona en ROMs compiladas con **test-keys**.
